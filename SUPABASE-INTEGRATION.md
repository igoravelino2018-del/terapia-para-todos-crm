# Integração compartilhada

Branch de desenvolvimento criada para conectar o protótipo ao Supabase. O banco já contém parceiros, pacotes, oportunidades, encaminhamentos, reposições, auditoria, membros e comandos transacionais. A interface deve usar a URL pública do projeto e uma chave publicável configurada no ambiente de implantação, sem armazenar credenciais privadas no repositório.
